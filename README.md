# CloseUp

Application mobile sociale pour connecter locaux et voyageurs autour de moments.

## Stack
- Expo / React Native
- TypeScript
- Supabase
- PostgreSQL / Realtime

## Développement

```bash
cd app
npm install
npx expo start
```

Configurer les variables `EXPO_PUBLIC_SUPABASE_URL`, `EXPO_PUBLIC_SUPABASE_ANON_KEY` et `EXPO_PUBLIC_MAPBOX_TOKEN` dans `.env`.
